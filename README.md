# Lumina Match

A curated dating club for health-minded singles in Bangkok.

## About

Lumina Match is a premium dating service that hosts morning events, facilitates real conversations, and connects people who have their lives together. "Meet someone worth waking up for."

## Tech Stack

- React 19 + Vite
- Tailwind CSS
- React Router DOM
- Lucide React (icons)

## Getting Started

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Pages

- `/` - Landing page
- `/apply` - Passport application form
- `/about` - About Lumina Match
- `/faq` - Frequently asked questions
- `/events` - Upcoming and past events

## Features

- Multi-step Passport application wizard
- Interactive Lumi chat widget
- Event filtering by format
- Mobile-responsive design
- SEO-optimized with Open Graph tags
